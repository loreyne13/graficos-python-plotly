Visualização de Dados com Python e Plotly

Este repositório documenta o meu progresso prático na criação de gráficos e painéis interativos utilizando Python. O objetivo é transformar bases de dados em informações visuais claras e de fácil interpretação.

Bibliotecas Utilizadas
- **Python**
- **Pandas**: Para importação, agrupamento e tratamento dos dados.
- **Plotly Express**: Para a geração de gráficos interativos.

Gráficos Desenvolvidos
À medida que os estudos avançam, novos scripts são adicionados a esta lista:
- [x] **Gráfico de Barras:** Análise do total de vendas agrupado por categoria de produtos.

Como visualizar os resultados
Os gráficos interativos gerados por este projeto são exportados em formato web. Para interagir com as visualizações (passar o rato, fazer zoom), basta abrir o ficheiro `.html` correspondente (ex: `meu_grafico.html`) num navegador de Internet normal (Chrome, Edge, etc.).
